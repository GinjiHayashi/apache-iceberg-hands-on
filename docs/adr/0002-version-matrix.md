# 0002. バージョンの組み合わせを固定する

- 日付: 2026-09-26
- 状態: 採用

## 背景

Polaris、Spark、Trino、Iceberg は、バージョンの組み合わせによって互換性の問題が起きやすい。要件ではすべてのバージョンを明示的に固定することにしている。

## 検討した選択肢

- Spark 3.5.9 — 保守されており、Polaris 公式ガイドの例でも使われている。ただし v3 の variant 型や行の履歴を追う機能は Spark 4.0 以上でないと使えない
- Spark 4.1.3 — Iceberg 1.11 の標準の Spark バージョンで、最新の機能が使える。ANSI SQL モードが標準で有効
- Spark 4.2 — Iceberg 1.11 に対応するランタイムがない

## 決定

| コンポーネント | バージョン | リリース日 |
| --- | --- | --- |
| Iceberg（`iceberg-spark-runtime-4.1_2.13`、`iceberg-aws-bundle`） | 1.11.0 | 2026-05-19 |
| Spark | 4.1.3 | 2026-07-15 |
| Trino | 483 | 2026-07-17 |
| Polaris（server / admin-tool） | 1.7.0 | 2026-08-02 |
| PostgreSQL | 18.6 | 2026-09 |
| RustFS | 1.0.0 | 2026-09-16 |
| PyIceberg | 0.12.0 | 2026-09-01 |
| 初期化用: `alpine/curl` / `amazon/aws-cli` | 8.21.0 / 2.36.8 | Polaris 公式ガイドで使われているもの |

テーブルフォーマットは v2 で統一する。

## 理由

- 2026-09 時点で、それぞれの最新の安定版。Polaris 1.7.0 自体が Iceberg 1.11.0 を内部で使っている
- Spark 4.1 にすると、v3 の追加目標も実現できる
- Trino は 479 以降 JDK 25 が必要だが、公式イメージに同梱されている

## 影響

- Spark 4 の ANSI SQL モードで、不正な型変換はエラーになる。ハンズオンでは明示的に CAST する
- Iceberg 1.11 は Java 11 に対応しないので、Spark のイメージは Java 17 のものを使う
- バージョンを上げるときは、この ADR を置き換える新しい ADR を書く
